Como adicionar novos resumos

1) Salve o novo arquivo HTML na mesma pasta deste painel. 2) Abra este arquivo no editor. 3) No bloco const materiais = [...], adicione um novo item seguindo o modelo abaixo:

{
  grupo: "Fundamentos, Organização e Gestão do SUAS",
  titulo: "NOB SUAS 2012",
  subtitulo: "Responsabilidades, cofinanciamento, gestão e rede",
  arquivo: "nobsuas_resumo.html",
  status: "pronto"
}

Quando ainda não tiver o HTML, deixe arquivo: "" e status: "pendente".
